# CepFinder

Aplicação web desenvolvida para consulta rápida de endereços através de códigos postais (CEP).

## Sobre o Projeto

O CepFinder facilita a busca de informações de endereços (como rua, bairro, cidade e estado) a partir da inserção de um CEP válido, integrando uma interface simples com requisições assíncronas.

## Funcionalidades

* Consulta de CEP em tempo real.
* Preenchimento automático de campos de endereço.
* Interface limpa e intuitiva para o usuário.

## Tecnologias Utilizadas

* HTML
* PHP
* JavaScript

## Como Executar

1. Certifique-se de ter um ambiente de servidor local configurado com suporte a PHP (como XAMPP, WampServer ou Docker).
2. Clone este repositório ou baixe os arquivos no diretório raiz do seu servidor web (ex: `htdocs` ou `www`).
3. Acesse o projeto através do seu navegador no endereço local correspondente (ex: `http://localhost/CepFinder/`).
